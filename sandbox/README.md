# NEON LAB — интерактивная песочница для PixLast

Маршрут: `/PixLast/sandbox/` (или локально `/sandbox/`). Это **самостоятельная страница** на Phaser 3; существующая сюжетная миссия и ее сохранения не меняются.

## Возможности

- 12 типов оригинальных предметов: герой, информатор, дрон, капсула, фонарь, контейнер, бочка, терминал, вывеска, конус, голографический маяк и машина. Новые объекты создаются программно в Phaser, существующие спрайты переиспользуются из `../assets/`.
- Каталог **244 PixelFX-эффектов** в 21 категории: поиск по идентификатору/названию, фильтр, установка в сцену кликом или перетаскиванием из панели.
- На сцене: выделение, перетаскивание, включение сетки 16 px, горизонтальная камера, включение/выключение дождя. Для перекрытых элементов есть список слоёв.
- Инспектор: X/Y, масштаб, угол, глубина, прозрачность, горизонтальное отражение; дополнительно для эффектов — палитра, скорость, повтор, воспроизведение/пауза.
- Можно привязать эффект к выбранному предмету. Он будет двигаться вместе с ним. При непосредственном перетаскивании эффекта привязка снимается.
- Пуск/пауза/повтор всех эффектов, дублирование и удаление, история из 50 снимков (Ctrl+Z/Ctrl+Y), автоматическое сохранение в `localStorage`, экспорт/импорт JSON с проверкой схемы.
- Управление на планшете: касание/перетаскивание по сцене, кнопки для смещения камеры, инспектор под сценой.

## Работа

1. Перейдите из игры по ссылке **ПЕСОЧНИЦА** или откройте `sandbox/index.html`.
2. Выберите слева **Предметы**, нажмите на карточку, затем на нужное место на сцене; повторите для нескольких предметов. Для переноса уже поставленного выберите «Выделить» (клавиша `V`).
3. Откройте вкладку **Эффекты**, выберите категорию или используйте поиск. Нажмите эффект и кликните по сцене — он появится как самостоятельный элемент.
4. Чтобы прикрепить эффект, сначала выделите предмет, затем выберите эффект слева и нажмите **Применить выбранный эффект** в инспекторе. Выделенный объект сохраняется, пока вы выбираете эффект в библиотеке.
5. Настройте параметры справа, нажмите **Воспроизвести**. Ползунок под сценой перемещает камеру. Кнопки JSON позволяют сохранить или перенести настройки на другой браузер.

## Библиотека эффектов

Оригинальные модули `patch-gg/pixelfx` (MIT, зафиксирован commit `a84159688af3ca37a4be05a0d422b94451b2e24e`) загружаются **по запросу**, чтобы не тянуть сразу 244 модуля. Сначала проверяется `../vendor/pixelfx`, затем CDN `cdn.jsdelivr.net`. Для запуска Phaser 3.90.0 аналогично проверяется локальный файл `../vendor/phaser.min.js`, затем два CDN.

- При доступном PixelFX используется **настоящий исходный код эффекта**: `createFx` / `createFrame` / `composite` внутри Phaser CanvasTexture.
- Если PixelFX недоступен, песочница продолжает работать и показывает **упрощённые демонстрационные кольца и искры** вместо точного оригинального эффекта. Индикатор сверху предупреждает об этом. Для оценки конкретного PixelFX нужен доступ к CDN или локальная установка библиотеки (`python install-deps.py --with-pixelfx` из корня PixLast).
- Не более 90 элементов в одной сцене. При увеличении числа сложных эффектов может снижаться FPS; закадровые текстуры не перерисовываются. Эффекты располагаются на фоне существующей городской сцены, а не влияют на игровой процесс.

## Файлы

- `sandbox/index.html` — интерфейс и три панели.
- `sandbox/style.css` — оформление и адаптивность.
- `sandbox/bootstrap.js` — загрузка Phaser.
- `sandbox/catalog.mjs` — проверенный список идентификаторов PixelFX, палитры и предметы.
- `sandbox/model.mjs` — чистая модель сцены, экспорт, нормализация JSON.
- `sandbox/editor.mjs` — Phaser-сцена и инструменты редактора.
- `tests/sandbox.mjs` — проверки модели, контракта библиотеки и ссылок.

Запуск из корня репозитория: `python -m http.server 8080` и затем `http://localhost:8080/sandbox/`. Для публикации достаточно статического GitHub Pages из корня `main`, отдельный backend не нужен.

## Ограничения

Песочница — испытательный редактор эффектов, **не** игровой level designer. Она пока не добавляет физику предметам, AI, коллизии, скрипты или генератор уровней основной миссии. Сохранённые JSON-файлы не исполняются и проходят проверку допустимых полей. Нет серверного хранения или синхронизации между устройствами.

Лицензии третьих сторон и уведомления: [`../THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md). Шрифт из галереи PixelFX не используется.
