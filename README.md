# NEON 04:19 — Playable Concept

Небольшая самостоятельная игра-прототип в атмосфере кинематографичного киберпанк-пиксель-арта. **Не входит** в репозиторий `i12309/Games`. Не использует графику, персонажей, музыку или игровой код *The Last Night*.

**Движок:** Phaser **3.90.0**; **эффекты:** оригинальный [PixelFX](https://github.com/patch-gg/pixelfx) `patch-gg/pixelfx` (фиксированный коммит `a84159688af3ca37a4be05a0d422b94451b2e24e`) и встроенные запасные эффекты. **Графика:** оригинальная, процедурно созданная скриптом `build_assets.py` (Pillow). **Язык:** JavaScript, HTML, CSS. **Бэкенд не нужен.**

## Быстрый запуск

**Самый простой вариант:** откройте соседний файл `NEON_0419_onefile.html` в браузере. Для загрузки Phaser нужен доступ в интернет при первом открытии. Вся графика встроена внутрь этого файла; после загрузки Phaser игра запускается без сервера.

**Для разработки (отдельные файлы):**

- Windows: `run-local.bat` (нужен Python 3 с `py -3`).
- Linux / macOS: `./run-local.sh` (нужен Python 3).
- Либо вручную: `python -m http.server 8080`, затем `http://localhost:8080`.

По умолчанию Phaser подгружается с jsDelivr. PixelFX подгружается из исходного репозитория через jsDelivr; если источник недоступен, остаются работающие встроенные эффекты (дрон, импульс, подбор, миссия).

### Полностью автономный запуск (после первичной установки)

В каталоге демки один раз запустите:

```sh
python install-deps.py --with-pixelfx
```

Скрипт локально скачает `vendor/phaser.min.js` и исходники PixelFX в `vendor/pixelfx`, после чего модульная версия будет работать без интернета через локальный HTTP-сервер. Без `--with-pixelfx` подгружается только Phaser; в отсутствие интернета PixelFX будет заменён на локальные резервные эффекты.

## Как играть

| Кнопка | Действие |
| --- | --- |
| `A` / `D`, стрелки ← → | Ходить |
| `Shift` | Бежать |
| `Space` / `W` | Прыгнуть |
| `E` / `Enter` | Говорить, осмотреть, забрать, открыть |
| `F` | Электромагнитный импульс, оглушает дрон на несколько секунд |
| `Esc` | Закрыть диалог |

На планшете есть сенсорные кнопки. Звук выключен по умолчанию, включается сверху справа.

## Прохождение

1. Найти человека в красном пальто у лапшичной, нажать `E`, прочитать короткий разговор.
2. Идти направо и забрать светящуюся капсулу памяти из архива (`E`).
3. При встрече с дроном использовать `F` — это необязательно для победы, но демонстрирует PixelFX EMP.
4. Дойти до зоны `MEMORY`, активировать терминал (`E`).
5. Войти в шлюз `EXIT` в конце улицы (`E`).

После миссии появляется завершение и кнопка повторного прохождения.

## Технические детали и ограничения

- Базовое разрешение игры 640×360, слой города шириной 2800 пикселей. Phaser Arcade Physics: ходьба, прыжок и столкновение с землёй. Параллакс, дождь, вспышки, мерцание неона, поезд и машина находятся в разных слоях.
- В `PixelFX` используется **настоящий код библиотеки**, не перерисованный скриншот: `src/core/index.js`, `src/fx/scifi/emp-blast.js`, `src/fx/pickups/collect-burst.js`. Для динамической текстуры Phaser выполняется `update` → `clearFrame` → `draw` → `composite` с кадровой частотой вывода 24 к/с. Если библиотека не загрузилась, используются эффекты Phaser.
- Для простоты это **одна горизонтальная сцена**, без врагов с ИИ, инвентаря, сейвов, сюжетных развилок и настоящей системы освещения/теней.
- Phaser не включён в ZIP бинарным файлом, чтобы не раздувать прототип; можно использовать CDN или установить локально через скрипт. На локальной машине с доступом в интернет браузерная демка стартует сразу.
- В среде подготовки проекта доступ браузера к внешним сетям заблокирован: пройдены проверки синтаксиса JS, структуры файлов и PNG, но реальное выполнение движка в Chromium здесь не было проверено. Пожалуйста, при тестировании сообщите об ошибках в консоли, если они возникнут.

## GitHub Pages (PixLast)

Этот проект опубликован отдельно от `Games`. Планируемый URL: **https://i12309.github.io/PixLast/**.

В настройках GitHub откройте **Settings → Pages**, выберите
**Build and deployment → Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)**.
После включения публикации сайт будет обслуживаться прямо из корня `main`.
`index.html` — входная страница. Сборка и backend не требуются.

Внимание: Phaser 3.90.0 загружается через jsDelivr с резервным CDN cdnjs.
Для первого запуска браузер должен иметь доступ к одному из них. PixelFX (зафиксированный GitHub commit) тоже может загружаться из CDN, но при недоступности используется встроенный резервный эффект.
